# 數位校園共享站 — 網站開發規劃書

## 一、專案概述

| 項目 | 說明 |
|------|------|
| 專案名稱 | 數位校園共享站 |
| 目標 | 建構一個整合校園資訊、選課、公告、社團等功能的綜合性校園入口網站 |
| 技術架構 | Vercel（前端部署）+ Firebase（後端服務） |
| 開發方式 | 前後端分離，採用 JAMstack 架構 |

## 二、技術選型

| 類別 | 技術方案 | 選擇理由 |
|------|----------|----------|
| 前端框架 | Next.js 14+（App Router） | Vercel 原生支援，SSR/SSG 靈活切換，SEO 友善 |
| 開發語言 | TypeScript | 型別安全，降低維護成本，提升程式碼品質 |
| 樣式方案 | Tailwind CSS | 實用優先（Utility-first），快速迭代 UI |
| 認證服務 | Firebase Authentication | 支援多種登入方式，與 Next.js 整合便利 |
| 資料庫 | Cloud Firestore | NoSQL 即時資料庫，自動擴展，離線支援 |
| 檔案儲存 | Firebase Cloud Storage | 與 Firebase 生態系整合，適合圖片/文件上傳 |
| 部署平台 | Vercel | 自動 CI/CD，全球 CDN，與 Next.js 同公司維護 |
| 版本控制 | Git + GitHub | 團隊協作，變更追蹤 |

## 四、功能規劃與開發順序

### 第一階段：基礎架構（第 1-2 週）
| 工作項目 | 說明 | 優先級 |
|----------|------|--------|
| 專案初始化 | 建立 Next.js 專案，配置 TypeScript + Tailwind | 高 |
| Firebase 專案設定 | 建立 Firebase 專案，啟用各項服務 | 高 |
| 環境變數管理 | 設定 `.env.local` 與 Vercel 環境變數 | 高 |
| 專案目錄結構 | 建立標準化的資料夾結構 | 高 |

### 第二階段：用戶認證系統（第 2-3 週）
| 工作項目 | 說明 | 優先級 |
|----------|------|--------|
| 電子郵件/密碼登入 | Firebase Email/Password Auth | 高 |
| Google 登入 | 整合 Google OAuth（學校帳號 + 個人 Gmail） | 高 |
| 電子郵件驗證 | 註冊後發送驗證信，未驗證限制功能 | 高 |
| 忘記密碼 | 密碼重設流程 | 中 |
| AuthProvider | React Context 管理全域認證狀態 | 高 |
| 路由保護 | Next.js Middleware 驗證登入狀態 | 高 |

### 第三階段：角色權限管理（第 3-4 週）
| 工作項目 | 說明 | 優先級 |
|----------|------|--------|
| 用戶資料模型 | Firestore `users` Collection 設計 | 高 |
| 角色系統 | Admin / Teacher / Student 三種角色 | 高 |
| 權限控管 | 基於角色的功能存取控制 | 高 |
| 管理後台 | 用戶管理、角色分配介面 | 中 |

### 第四階段：核心功能模組（第 4-8 週）

#### 4.1 校園公告系統
- 公告發布 / 編輯 / 刪除
- 分類標籤（校方公告、活動訊息、緊急通知）
- 即時推播（Firestore 即時監聽）
- 公告置頂與到期機制

#### 4.2 選課系統
- 課程列表與搜尋
- 課程時間表檢視
- 選課 / 退選功能
- 衝突課程檢查
- 選課人數上限控制

#### 4.3 社團活動管理
- 社團資料維護
- 活動發布與報名
- 活動參與紀錄

#### 4.4 校園地圖
- 校園建築與設施標註
- 教室位置查詢
- 搜尋功能

#### 4.5 學生事務
- 成績查詢
- 個人資料管理
- 課表檢視

## 五、Firestore 資料模型設計

### 5.1 users（用戶）
```
users/{uid}
├── email: string
├── displayName: string
├── photoURL: string | null
├── role: "admin" | "teacher" | "student"
├── department: string              // 系所
├── studentId: string | null        // 學號
├── teacherId: string | null        // 教師編號
├── emailVerified: boolean
├── createdAt: timestamp
└── updatedAt: timestamp
```

### 5.2 announcements（公告）
```
announcements/{id}
├── title: string
├── content: string
├── category: "official" | "activity" | "urgent"
├── authorId: string (ref → users)
├── isPinned: boolean
├── expiresAt: timestamp | null
├── createdAt: timestamp
└── updatedAt: timestamp
```

### 5.3 courses（課程）
```
courses/{id}
├── name: string
├── teacherId: string (ref → users)
├── department: string
├── semester: string
├── schedule: array                 // 上課時間
│   └── { day: string, period: string, location: string }
├── maxStudents: number
├── currentStudents: number
├── description: string
├── createdAt: timestamp
└── updatedAt: timestamp
```

### 5.4 enrollments（選課紀錄）
```
enrollments/{id}
├── studentId: string (ref → users)
├── courseId: string (ref → courses)
├── status: "enrolled" | "dropped" | "completed"
├── enrolledAt: timestamp
└── droppedAt: timestamp | null
```

### 5.5 activities（社團活動）
```
activities/{id}
├── title: string
├── description: string
├── organizerId: string (ref → users)
├── clubName: string
├── eventDate: timestamp
├── location: string
├── maxParticipants: number | null
├── currentParticipants: number
├── status: "upcoming" | "ongoing" | "ended"
├── createdAt: timestamp
└── updatedAt: timestamp
```

## 八、環境變數設定

### 本機開發（`.env.local`）
```env
# Firebase Client Config
NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
```

### Vercel 部署（環境變數面板）
```env
# Firebase Admin SDK（Service Account）
FIREBASE_SERVICE_ACCOUNT_KEY={"type":"service_account",...}

# 其他伺服器端環境變數
NEXT_PUBLIC_APP_URL=https://your-domain.vercel.app
```
