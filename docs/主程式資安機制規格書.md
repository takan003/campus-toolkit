## 一、驗證（Authentication）

### 1.1 帳密
- 儲存：`成員名冊!密碼` 欄，格式 `salt$iter:hex`（5000輪 `SHA256` + Pepper），舊 `salt:hex` 自動升級 `auth.js:92` / `main.js:688`
- Pepper：`PropertiesService PASSWORD_PEPPER`，無則回落 `TOKEN_SECRET`（待改獨立）
- 複雜度：`>=8 +a-z +A-Z +0-9` `main.js:820`
- 遷移：明文比對成功自動 `hashPassword` 寫回

### 1.2 Email OTP
- 產生：`emailOtpSend` 6位 `100000-999999`，`Cache eotp_ 600s` 一次性，`eotp_req_ 120s` 節流 `auth.js:295`
- 驗證：`emailOtpVerify` 比對後 `Cache.remove`  `auth.js:321`

### 1.3 TOTP
- 演算：RFC6238 `HMAC-SHA1` window `T±1` `auth.js:153`，`totp_used_ 90s` 防重放
- 密鑰：存 `TOTP密鑰` 欄，`totpGenerateSecret:191` 產生；QR 由前端 `qrcodejs` 本地產生，後端僅回 `otpauthUrl` `main.js:819` / `account.html:9`

### 1.4 Google OAuth
- `state` 以 `nonceCreate` + `Cache oauth_role_ 600s` 保護 `main.js:182`，`UrlFetch` 交換 `code→access_token→userinfo`，scope `email profile` `appsscript.json:13`
- 密鑰：`OAUTH_CLIENT_SECRET` 存 `PropertiesService`，格式 `^GOCSPX-[A-Za-z0-9-_]+$` `main.js:488`

## 二、工作階段（Session）

### 2.1 簽章
- 格式：`b64url(payload).b64url(HMAC-SHA256)`，payload `email|role|themeId|exp`
- 種類：`sessionSign exp+7200` / `tokenSign exp+300` / `passwordResetTokenSign exp+1800` `auth.js:17`
- 密鑰：`TOKEN_SECRET` 存 `PropertiesService`，不存在自動 `UUID+UUID` `main.js:658`
- 驗證：`sessionVerify` 檢 `exp` + HMAC + `revoked_` Cache `auth.js:57`

### 2.2 撤銷
- `invalidateSession(token)` 寫 `revoked_{sha256(token)} 7200s` `main.js:758`，`sessionVerify` 擋 `已撤銷`；前端 `idle_timeout.html:66` 逾時/登出調用
- 待辦：`tokenVersion` 持久欄 + `jti` 以支援持久撤銷與滑動續簽

### 2.4 暴力防護（H3）
- `Cache login_fail_{role}_{account} 900s` 5次鎖15分，成功清除，失敗寫 `logActivity 登入失敗` `main.js:662`

### 2.5 重設密碼一次性（H4）
