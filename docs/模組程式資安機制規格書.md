# 模組程式資安機制規格書

> 專案：數位校園GAS站外掛模組（`數位校園GAS站模組 - *`）
> 版本：v326 對應（115.09.06）
> 適用：所有新模組開發者
> 關聯：`主程式資安機制規格書.md` / `模組程式開發架構與規格書.md` / `CSS主題細緻化規劃書.md`

---

## 一、總則

模組為獨立 GAS Web App，與主程式共用 `TOKEN_SECRET` 完成身分互信。除遵循本規格外，亦須遵守主程式 `H/M/L` 改進要求（KDF、XSS、閒置等）。

**模組的資安機制應與主程式完全對齊**，包括密碼雜湊、Session 管理、暴力防護、閒置逾時、審計紀錄等。本規格書以主程式 v326 為基準。

## 二、活化協議（一次性）

### 2.1 管理員輸入
- `模組試算表雲端連結`：`https://docs.google.com/spreadsheets/d/{id}`
- `模組部署網址`：`https://script.google.com/macros/s/{id}/exec`

### 2.2 主程式執行（`main.js:installModule`）
1. `openById(id)` 開啟模組試算表，讀 `模組資訊` Key-Value
2. 正則驗證 `^https://script.google.com/macros/s/[A-Za-z0-9-_]+`，`followRedirects:false`
3. 寫入 `installNonce` 至 `模組資訊!A{last+1}`，`UrlFetch POST {page:install, code:installNonce, secret:TOKEN_SECRET}`（現行，**待改短期 JWT** `aud=deployId,exp+300`）
4. 成功後於主程式 `模組` 工作表新增列（含顯示名稱、版本、作者、部署ID 等），`顯示` 強制 `否`
5. 安裝失敗須 `logActivity` 記錄（含模組名稱、錯誤原因）

### 2.3 模組設定工作表
- 必須含 `TOKEN_SECRET`（活化後由主程式寫入）
- 可含 `CSS主題ID`（強制主題，空值不強制）等模組自訂欄位

## 三、每次點選（方案B Token 傳遞）

### 3.1 主程式簽發
`_signModuleUrls` `main.js:1422` 產生 `payload`：
```
{
  email, role, name,
  學校全稱, 學校簡稱, 系統自命名, 學年度, 教育部學校代碼,
  承辦師長, 承辦師長電子郵件地址,
  原創版權宣告, 贊助廣告開關,
  成員名冊雲端連結, 主系統部署網址,
  themeId, forcedTheme,
  exp: now+7200, iat: now
}
```
以 `HMAC-SHA256(TOKEN_SECRET)` 簽章為 `token`，導向 `模組部署網址?token=xxx`（**遷移目標** `?sid=`，見主程式 H1）。

### 3.2 模組驗證（`auth.js:sessionVerify` 須與主程式一致）
```
Token = b64url(JSON).b64url(HMAC)
1. 讀自身 `設定!TOKEN_SECRET`
2. 驗 `exp` + HMAC + `revoked_` Cache + `revoked_jti_` Cache
3. 檢查 `tokenVersion`：模組端名冊版本 > payload 版本 → 拒絕
4. 成功 → 取出 payload，寫入 localStorage `moduleConfig`
5. 失敗 → 導回主程式重新登入
```

> 失敗須 `logActivity`（若有活動紀錄連結）。

### 3.3 協定要求
- 模組 `doGet` 須支援 `resolveRequestToken(e)` 接受 `?token=`
- `sessionVerify` 須檢查 `revoked_`（閒置逾時/登出撤銷）與 `revoked_jti_`（登出/改密撤銷）
- 模組內轉頁一律讀 `localStorage moduleConfig`，不重傳 token

## 四、密碼與成員

### 4.1 密碼儲存格式
與主程式完全一致：
- **新密碼**：`pbkdf2$salt$iter:hex`，PBKDF2-HMAC-SHA256，`iter` 由 `設定!密碼雜湊迭代次數` 決定（填入值 × 1000，範圍1000-100000，預設10000）
- **舊格式**：`salt$5000:hex`（KDF 5000輪字串迭代）、`salt:hex`（SHA256 plain）
- **登入時自動升級**：明碼→PBKDF2、舊KDF→新PBKDF2、空 Pepper→當前 Pepper

### 4.2 Pepper
- `PropertiesService` 讀 `PASSWORD_PEPPER`，無則自動產生 UUID+UUID 作為後備
- `verifyPassword` 支援空 Pepper 降級驗證（相容舊密碼）
- 登入成功後自動將空 Pepper 密碼以當前 Pepper 重新雜湊

### 4.3 密碼複雜度
- `>=8` 字元，含 `+a-z +A-Z +0-9`
- 重設密碼時須校驗

### 4.4 Email 正規化
- 全路徑 `trim().toLowerCase()` + 正則 `^[^\s@]+@[^\s@]+\.[^\s@]+$`
- 登入、重設密碼、帳號管理等讀取路徑須一致

### 4.5 暴力防護（雙重機制）
- **Cache 快速**：`login_fail_{role}_{account}` 900s，5次鎖15分
- **名冊持久欄**：`失敗次數` / `鎖定至` 欄位，5次鎖15分
- 成功登入清除兩者
- 統一回傳「帳號或密碼錯誤」，防止帳號列舉

## 五、Session 管理

### 5.1 Token 格式
與主程式一致：`b64url(payload).b64url(HMAC-SHA256)`
- payload 含 `email|role|themeId|exp|tokenVersion|jti`
- `exp` 採滑動續簽：`now + min(idleTimeout+60, 7200)`
- `jti` 用於精準撤銷（登出/改密時撤銷特定 token）

### 5.2 撤銷機制
- **閒置逾時/登出**：`revoked_{sha256(token)}` Cache 7200s
- **登出/改密**：`revokeTokenByJti` 寫 `revoked_jti_{jti}` Cache 7200s
- **改密/重設密碼**：`_bumpTokenVersion` 持久失效（名冊 `tokenVersion` +1）
- 模組端 `sessionVerify` 須同時檢查 `revoked_` 與 `revoked_jti_`

### 5.3 閒置逾時
- 參數 `設定!閒置過久超過分鐘後登出` → `window._IDLE_MIN`
- 前端 `idle_timeout` 監聽 `mousedown/mousemove/keydown/touchstart/scroll`，`WARN 60s` 倒數
- 逾時調 `invalidateSession(token)` 後重導
- 後端 `sessionVerify` 檢查 `exp`（已縮至 `idleTimeout+60s` 滑動續簽）

## 六、主題同步（CSS 主題細緻化）

- 優先級：`模組強制 > 主程式強制 > 模組名冊 CSS主題ID > token 主題 > localStorage > 模組預設` `主程式資安機制規格書 §8-1`
- 注入順序：`window.GAS_*` 必須在 `include('theme')` **之前**
- 切換後 `updateUserTheme` 寫回獨立成員名冊 `CSS主題ID`，並 `syncThemeToMain` POST `theme_sync` 同步主程式

---

## 七、XSS / CSRF

- 所有使用者可控輸出（如模組顯示名稱、試算表內容）須 `escHtml` 或 `<?=`
- `showMessagePage` 對 `msg` 須跳脫；JS 注入用 `JSON.stringify`
- `google.script.run` 須 `nonceCreate/Verify` `Cache 600s` 一次性

---

## 八、審計與最小權限

- `logActivity` 寫 `活動紀錄` 6欄，失敗路徑（登入/OTP/TOTP/鎖定/安裝）皆須記錄
- `getMemberRoster`/`getActivityLog` 僅 `openById(雲端連結)`，已移除 `DriveApp.getFilesByName` 劫持備援
- `appsscript.json` `USER_DEPLOYING` 需文件化必要性並限縮 Drive scope
- 密鑰校驗：`TOKEN_SECRET >=20` 含英數

---

## 九、重設密碼（一次性連結）

- `pwd_reset_used_{sha256(token)}` Cache 1800s，二次使用回「已使用過」
- `pwd_reset_req_{account}` Cache 120s 節流，防止重設連結洪泛
- 重設後 `_bumpTokenVersion` 使所有舊 token 失效

## 十一、驗證清單

- `?token=` 可登入；`token` 洩漏於 Referer 前已考慮其他防護
- 舊 `salt:hex` / `salt$5000:hex` 帳號可登入並自動升級為 `pbkdf2$salt$iter:hex`
- 空 Pepper 密碼驗證成功後自動以當前 Pepper 重新雜湊
- 5次錯密鎖15分（Cache + 持久欄），`revoked` + `revoked_jti` 後舊 token 失效
- 改密/重設密碼後 `tokenVersion` +1，所有舊 token 失效
- `quickchart.io` 離線仍可產生 QR
- `escHtml` 對 `<script>` 跳脫成功
- 安裝失敗有審計紀錄
